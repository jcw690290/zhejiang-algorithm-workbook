接口与连接说明

需要支持 POST /chat/completions、Bearer 密钥和浏览器跨域请求（CORS）的接口。基础地址应包含服务商要求的版本路径，例如 /v1；本页只补全 /chat/completions。此模式不支持原生 Responses、Claude Messages 或 Gemini 格式。上限参数请按服务商文档选择。

直接打开 HTML 时，接口还需允许来源 null；使用 GitHub Pages 时，需允许你的站点来源。网络、CORS、证书及混合内容问题可能显示同一种连接错误，页面无法绕过这些限制。仅支持 HTTPS；本机 localhost / 127.0.0.1 / [::1] 可使用 HTTP。

测试连接也可能计费。停止等待或超时只能中断本页请求，服务商仍可能继续生成并计费。
